# 对决胜负预测算法

从油猴插件逆向的对决模拟算法，可用于武林大会竞猜押注。

## 核心公式

### 1. 属性基础分

```
base = 等级 × 5 + 力量 × 0.8 + 敏捷 × 0.8 + 速度 × 1.0 + 生命 × 0.2
```

### 2. 技能总分

对每个技能：
```
skillScore = 技能基础分 + 技能等级 × 5
```

全部技能求和后，再加组合加成（一次性）：
- 如来神掌 +30 / 装死 +40 / 嗜血 +25 / 大海无量 +25
- 均衡发展 +50 / 势如暴雨 +20 / 真·企鹅吼 +20

### 3. 武器总分

对每把武器：
```
weaponScore = 武器基础分 + 强化等级 × 6
```
全部武器求和后，再加武器数量分：`weaponCount × 10`

### 4. 总战力

```
total = base + skillTotal + comboBonus + weaponTotal + weaponCountBonus
```

## 克制修正 (KD Rating)

| 条件 | A 修正 |
|------|--------|
| A有 如来神掌 + B有 装死 | +15 |
| B有 大海无量 + A有 嗜血 | -10 |
| A有 胶水 + B无 避重就轻/凌波微步 | +15 |
| A有 势如暴雨 + A武器≥2 + B武器<2 | +20 |
| A有 均衡发展 | +30 |
| B有 均衡发展 | -30 |

修正后：
```
totalA += kdRating
totalB -= kdRating
```

## 胜率换算

```
diff = totalA - totalB

winProb = 50 + clamp(diff / 30, -45, 45)
winProb = clamp(winProb, 1, 99)
```

即每 30 分战力差 ≈ 1% 胜率偏移，最高 99%，最低 1%。

> 注意：实际对战受随机因素（暴击、闪避等）影响，公式仅作参考。

## 使用方式

武林大会竞猜时，输入两人属性/技能/武器，按以上公式算出战力差 → 胜率。胜率 > 60% 可考虑押注，> 70% 强烈推荐。
