# 战斗机制

## PVE 战力公式
PVE战力 = max(1, round(属性分 + 武器分 + 技能分 + 装备百分比分 + 职业分 + 称号分))

### 属性分
maxHp = maxHpBase + floor(maxHpBase * 职业生命百分比 / 100)
属性分 = round(maxHp * 1.15 + 力量 * 18 + 敏捷 * 14 + 速度 * 14 + 等级 * 30)

### 武器分
per weapon: round(avg_dmg * 7 + weapon_min_level * 8 + refine_level * 42 + 特效分(+70 if 特效) + 投掷分(+36 if throwable) + 魂珠分(魂珠总和 * 12))

### 技能分
round(type_weight * skill_level * level_coeff)
level_coeff = 0.8 + min(level, max_level) / max_level * 0.6

**类型权重**: 属性48, 被动72, 攻击92, 持续88, 斩杀120, 控制98, 吸血105, 保命115, 反弹95, 反击92, 恢复88, 连携110, VIP130, 辅助75, 未知70

### 装备百分比分
14种属性按权重计算（武伤42最高, 命中18最低），单项上限300点

### 职业分
round(260 + 觉醒加成(420 if awakened) + 主动技能数*90 + 被动贡献 + 属性贡献)

### 称号分
无称号=0, 普通=420, 至尊=1300

### 段位
0新锐 / 1000进阶 / 3000精锐 / 7000英杰 / 15000宗师 / 30000传说

## 场景属性倍率
秘境100%, 斗神塔/Boss 80%, 乐斗PvP 30%, 锦标赛/大会 0%

## 属性上限
闪避上限70%; 减伤100%=无敌; 速度差>20%可触发额外回合; 吸血50%概率触发; 其余无上限

## 通用垃圾词条
治疗%(除圣骑), 受治疗%, 技伤%(圣骑/气功), 力量(圣骑/气功), 敏捷(圣骑/狂战)

## 减伤等效HP公式
1%减伤等效HP = 当前总HP * 1% / (1 - 当前总减伤%)

## 战斗核心机制
- 暴击: crit_pct 概率触发, 伤害 × crit_dmg_pct
- 闪避: dodge_pct vs hit_pct 判定
- 经验公式: floor(基础EXP × expMul) × character.expMul
- 连击: 额外攻击一次, 造成基础伤害的70%
- 装死: 首次致死伤害以1HP存活, 每场限一次
- 即死: 对领主/首领免疫

## 属性效果详解
| 属性 | 效果 |
|------|------|
| 力量 | 增加基础攻击力, 影响力量系数技能伤害 |
| 敏捷 | 影响闪避率和连击率的基础判定 |
| 速度 | 决定出手顺序和出手频率。速度差>20%可触发额外回合 |
| 生命 | 增加最大生命值上限 |
| 武伤% | 按百分比提升所有武器伤害, 乘算叠加 |
| 闪避% | 完全回避攻击的概率（上限70%） |
| 连击% | 攻击后追加一次额外攻击的概率 |
| 暴击% | 造成1.5倍伤害的概率 |
| 吸血% | 50%概率触发, 按伤害百分比回血 |
| 减伤% | 减最终伤害（100%=无敌） |
| 格挡% | 概率格挡攻击, 大幅减少伤害 |
| 技伤% | 提升职业技能伤害 |
| 治疗% | 增强治疗/护盾/复活效果 |

## 智能装备评分公式
装备评分 = 攻击×2 + 防御×1.5 + 速度×1.5 + 暴击×3 + 命中×2 + 闪避×2

## 装备强化
每强化1级提升4%主属性:
- 头饰/护甲: +4%生命（极高优先级）
- 护腕: +4%力量（高）
- 腰带/鞋子: +4%速度（中）
- 项链: +4%连击率（中）

## 组队秘境
人数缩放(1-4人): HP ×1.0/1.7/2.4/3.1, 属性 ×1.0/1.15/1.3/1.45, 经验 ×1.0/1.15/1.3/1.45
无还魂丹复活, 周四/六对非会员开放, 创建房间需会员
Boss额外掉落率: 青铜16%→传说42%
锻造石奖励: 青铜16→大师150（根据秘境等级）
