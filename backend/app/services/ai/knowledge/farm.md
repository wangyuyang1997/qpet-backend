# 农场系统

## 每日重置时间
- 快速乐斗(NPC): 早8点（v4.1起取消上限）
- 斗神塔: 凌晨0点, 每天6次
- 农场广告奖励: 每天5次, 冷却30分钟

## 地块解锁
| 等级 | 地块 |
|------|------|
| Lv1-9 | 3块 |
| Lv10-13 | 5块 |
| Lv14-16 | 8块 |
| Lv17 | 10块 |
| Lv18+ | 12块 |

VIP黑土地(vipSlotIndex): 收获经验+50%, 不可被偷, 不可加速, 默认保护

## 每日限制
| 限制项 | 数值 |
|--------|------|
| 收获经验上限 | 80EXP/天 |
| 照料(浇水)上限 | 5次/天 |
| 偷菜上限 | 50次/天 |
| 广告奖励 | 5次/天, 间隔30分钟 |
| 访问奖励 | 5EXP/天 |
| 图鉴收集奖励上限 | 20EXP/天 |
| 每日任务奖励上限 | 30EXP/天 |

## 作物品质
普通70%(1.0x), 精良25%(1.2x), 稀有5%(1.5x)
收益公式: expReward = max(2, round(round(10*(time/60)^0.6)*rarityMult))
种子成本: seedCostExp = max(1, round(expReward*0.48))
rarityMult: 普通1, 精良1.15, 稀有1.35, 传说1.6

## 作物枯萎
成熟后24小时收割窗口, 超时枯萎不可收获

## 道具系统（消耗EXP）
| 道具 | 消耗 | 说明 |
|------|------|------|
| 加速1h | 15EXP | 黑土地不可用 |
| 保护2h | 15EXP | 防偷, 黑土地默认保护 |
| 双倍经验 | 20EXP | 收获经验翻倍 |

## 宠物守护
- QPet角色守护农场, 偷菜者触发宠物战斗
- petCaught: 是否被抓, petDamage: 伤害值
- petPenaltyExp: 被抓偷菜者损失的经验
- petBattleLog: 战斗日志

## 图鉴收集
- 首次收获某品质作物额外+2EXP（每日上限20）
- 追踪每个作物normal/fine/rare三档

## 每日任务
| 任务 | 要求 |
|------|------|
| harvest_count | 收获5次 |
| care_count | 照料3次 |
| plant_variety | 种植3种不同作物 |
| visit | 访问好友1次 |

## 播种建议
胡萝卜全场最优, Lv1用藜麦。VIP黑土优先种VIP专属作物(香荚兰等)
