# 战力评分体系

从第三方油猴插件逆向的量化评分规则，用于重开评估和装备推荐。

## 属性基础分

```
基础分 = 等级 × 5 + 力量 × 0.8 + 敏捷 × 0.8 + 速度 × 1.0 + 生命 × 0.2
```

速度权重最高（1.0），力量/敏捷平权（0.8），生命最低（0.2）。

技能分 = 基础分 + 等级 × 5，再加组合加成。

### 武器数量分

每装备一把武器 +10 分。

### 武器强化分

每 +1 强化等级 +6 分。例如 开山斧 +3 = 78 + 3×6 = 96 分。

## 战力总值

```
角色总战力 = 属性基础分 + 技能分总和 + 组合加成 + 武器分总和 + 武器数量分
```

| 对方有 均衡发展 | 我方 -30 |

## 重开评估应用

用此体系可量化角色战力：

- **总技能分** = Σ(技能基础分 + 等级×5) + 技能组合加成
- **总武器分** = Σ(武器基础分 + 强化×6) + 武器数量×10
- **属性分** = 等级×5 + 力量×0.8 + 敏捷×0.8 + 速度×1.0 + HP×0.2
- **角色总分** = 属性分 + 技能总分 + 武器总分

评估时不仅看"有没有神技"，还要看当前的量化得分与同级平均水平对比。
