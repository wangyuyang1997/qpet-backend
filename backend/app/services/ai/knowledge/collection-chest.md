# 典藏宝箱

## 基本规则

- 每日可开启多次，阶梯消耗
- 道具直入乐斗背包，核心展品同步进展厅
- 掉落：装备、魂珠、消耗品等

## 经验消耗阶梯

| 次数 | 消耗 |
|------|------|
| 第 1 次 | 免费 |
| 2 - 10 次 | 100 EXP / 次 |
| 11 - 20 次 | 200 EXP / 次 |
| 21 - 30 次 | 300 EXP / 次 |

## 掉落参考（从旧代码和社区数据）
- 王者宝箱最高 35% 概率出 Lv.5 魂珠
- 装备品质覆盖普通~传说
- 核心展品可同步到展览馆展厅

## 相关 API

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | /api/qpet/collection-chest | 宝箱状态（免费次数/经验消耗阶梯） |
| POST | /api/qpet/collection-chest/open | 开启宝箱 |
